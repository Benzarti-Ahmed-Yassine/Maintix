# MLOps Pipelines

This folder contains pipeline definitions and orchestration patterns for the MLOps lifecycle.

## Pipeline Families

- `training_pipeline` - Data preparation, model training, and experiment logging.
- `evaluation_pipeline` - Model evaluation and comparison.
- `validation_pipeline` - Data and model validation checks.
- `deployment_pipeline` - Packaging and releasing models.
- `monitoring_pipeline` - Continuous production monitoring.
- `drift_pipeline` - Drift detection and feedback loops.
- `retraining_pipeline` - Retraining orchestration and model refresh.
